# App React Native

Ce dossier contient l'application mobile qui consomme l'API du projet.

## Démarrage rapide

1. Installer Node.js et Expo CLI si ce n'est pas déjà fait.
2. Initialiser le projet avec Expo ou React Native CLI.
3. Installer les dépendances nécessaires (axios, navigation, etc.).
4. Lancer l'application avec `npx expo start` ou `npx react-native run-android`.

---

La structure sera créée automatiquement pour démarrer le projet.
